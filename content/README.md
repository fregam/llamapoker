# Content

Everything we publish outside the site's built-in pages, as Markdown, in the brand voice
(`brand/README.md`).

```
content/
  calendar.md     What's going out, when, and where
  articles/       Long-form pieces (draft → review → published)
  social/         Posts and captions, one file per post or thread
  research/       Weekly briefs from the research agent (planned)
```

Each file starts with a short header: title, status (draft / approved / published),
channel, date, and the site page it links to. Nothing is published without approval.
