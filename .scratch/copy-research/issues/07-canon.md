# 07 The canon

Status: ready-for-agent
Type: research

Build the source list for the full size (600 to 1,000) in `content/research/copy/canon.md`: classic
copywriters, practitioner-teachers with stated results, and published experiments (reading and
usability studies, plain-language research, published split tests). Each entry: what it is, the
result it claims, and whether that rests on an experiment or on reputation. For the pilot, read 20
(at least 8 experiments) into claims; each claim becomes a tag for readers or a countable measure
for ticket 04. Claims that break the hard limits (hype, false urgency, gambling glamour) are
listed as excluded, with the reason.
