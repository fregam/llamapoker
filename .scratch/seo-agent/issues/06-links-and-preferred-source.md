# 06 Links worth having, and the preferred-source link

Status: ready-for-agent

A new site with no links ranks slowly. Google's spam policy names "low-quality directory or
bookmark site links" and automated link creation, so this is a short list, not a campaign.

- [ ] Read the list from the reel ("A Growing List of Free Do-Follow Backlinks", Nick Nolan,
      Medium). Keep only places where a beginner poker player or a maker of study tools would
      really find us; write one line of reason per entry kept, and drop the rest.
- [ ] Add what the list misses and we already have a right to: the social profiles' bio links,
      the public GitHub repo's homepage field, Beehiiv's publication page.
- [ ] Output `content/seo/links.md`: at most 15 entries, each with the URL, why, what to write.
      The founder creates the accounts and submits, or says no. The agent submits nothing.
- [ ] Preferred source: a plain link `https://www.google.com/preferences/source?q=llamapoker.com`
      in the letter's footer and the site colophon. No Google script. Visible text: ask first.
