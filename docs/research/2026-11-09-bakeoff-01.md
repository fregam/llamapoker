# Bake-off 01

**Shot:** the Gentleman at the card table leans back, straightens his bow tie, then turns and
looks into the lens. 5 s, vertical, same keyframe for every model (a frame from Reel 001,
block 1) and the same prompt. Run on Comfy Cloud.

| | Kling 3.0 (partner API) | LTX-2.5 (open) | Wan 2.2 14B (open) |
|---|---|---|---|
| Cost | ~89 credits ≈ $0.42 | GPU time only | GPU time only |
| Render time | ~2 min | ~1 min | **~15 min** |
| Output | 720×1280, 24 fps | 704×1280, 24 fps, with audio | 720×1280, **16 fps** (needs interpolation) |
| On model / style | excellent | face drifts slightly, more realistic eyes | excellent |
| Acting | bow tie → hooves to table → slow turn to camera, deadpan stare | fists against chest instead of the bow tie | bow tie held, slow turn to camera |
| Camera | gentle, steady | strong push-in to a close-up | almost static |
| Hooves | read a bit like hands | clenched fists | read like hands |

## Verdict

- **Kling 3.0** is the best all-rounder for character acting: on model, follows direction,
  native vertical, ~$0.42 per 5 s.
- **Wan 2.2** matches Kling on fidelity, but is slow and static. It's still the open model we
  can drive with pose/motion control (Wan Animate) and with a trained LoRA, so it stays in the
  pipeline for controlled shots.
- **LTX-2.5** is fast and cheap with good camera energy, but weak on hands and identity. Use it
  for camera moves and hand-free shots: set pieces, inserts, the chip stack, the clock.

## Routing (first version)

| Shot type | Model |
|---|---|
| Character acting, hand/hoof action | Kling 3.0 |
| Performance-driven acting (your phone clip) | Wan Animate 2 vs Kling Motion Control (bake-off 02) |
| Camera moves, sets, props, inserts without hands | LTX-2.5 |
| Every shot, final pass | SeedVR2 → 1080×1920; interpolation for 16 fps sources |

## Fixes to carry forward

- Hooves: describe them only in positive terms ("dark cloven llama hooves") and never name
  fingers or hands, not even to exclude them, because naming them primes the model to draw them.
  Stage shots so hooves rest, press or push instead of gripping. Train the Gentleman LoRA so
  hooves stay hooves.
- LTX in Comfy templates defaults to landscape: override width/height nodes (398:372 = 720,
  398:360 = 1280).
